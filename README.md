# CohortAnalytics + Luma

This repository now holds two products:

1. **Luma** (`luma/`) — a fun, App Store-ready daily companion with cozy games and a paid **Plus** subscription. Start here if you want a consumer income app.
2. **Cohort Analytics** (repo root) — the original student / cohort dashboard.

## Luma (recommended)

```bash
cd luma
npm install
npm run dev
```

Read `luma/README.md` for the product, subscription design, and App Store launch steps. A Cursor launch agent lives at `.cursor/skills/app-store-launch/SKILL.md`.

